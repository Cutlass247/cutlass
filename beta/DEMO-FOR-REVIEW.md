# The demo video for Lemon Squeezy

## Don't send the marketing demo

`marketing/cutlass-demo.mp4` is a 30-second advert built from an HTML
animation that *mimics* the app's interface — the preview shows a drawn
silhouette rather than real footage, and the typography is cleaner than the
real thing. It is good at its job.

It is the wrong thing to send here. A reviewer is checking the product exists
and does what is claimed. A polished simulated interface is exactly what a
fraudulent application looks like, so at best it fails to answer the question
and at worst it invites a closer look.

Send a plain screen recording of the real application instead. It does not
need to be pretty. It needs to be obviously real.

## What to record

Two to four minutes, one take, no edits, no music, no captions. Record the
**whole screen** at 1080p so the Windows desktop and the app's own title bar
are visible — that framing is part of what makes it credible. OBS is fine.

Talk over it plainly, or add no audio at all. Either is fine.

**Show the desktop first.** Start on the desktop, open Cutlass from the Start
menu, and let it launch on camera. A reviewer wants to see it is an installed
Windows application, not a mockup.

**Then, in this order:**

1. **Import a real video.** Use something with speech in it. Let the import
   finish on camera, including the wait — the thumbnails and the waveform
   appearing prove it read a real file.
2. **Make an obvious edit.** Drag the clip on the timeline, split it, delete a
   piece. Scrub the playhead and let the preview follow.
3. **Show the transcript editing.** This is the product's distinctive claim, so
   it is the most useful thing to demonstrate: delete a word in the transcript
   and show the video cut with it.
4. **Show a paid feature.** Open the Looks or the Inspector and change the
   grade, so the preview visibly changes.
5. **Export.** Start a real export, let the progress bar move, and open the
   finished file in the Windows video player. **This is the single most
   convincing thing in the recording** — it proves the software actually
   produces the output it sells.
6. **Show the price.** Open the licence screen or the Buy button so the $49 is
   visible in the product itself, matching what the pricing document says.

## What matters in it

- **Do not cut anything out.** Waits and loading are evidence. A recording with
  no dead time looks edited, and edited looks staged.
- **Use real footage**, ideally your own — not a stock clip or a test pattern.
- Make sure the app's **title bar says Cutlass** and stays visible.
- If anything goes wrong mid-take, keep going. A small stumble is more
  convincing than a flawless run.

## Sending it

Lemon Squeezy asked by email, so reply to that thread with the recording
attached, or an unlisted YouTube/Drive link if it is too large. Include the
pricing breakdown in the same reply — `beta/PRICING.md`.

Worth adding one line pointing at the public product page
(https://cutlass247.github.io/) and the public releases
(https://github.com/Cutlass247/cutlass/releases), since a reviewer can
download and run the real thing themselves. That is stronger evidence than any
video, and most applicants cannot offer it.
